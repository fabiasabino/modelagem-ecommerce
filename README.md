# Modelagem de Sistema — E-commerce

## Sobre o projeto

Este repositório apresenta um projeto acadêmico desenvolvido durante a graduação em Análise e Desenvolvimento de Sistemas (ADS).

O projeto consiste na modelagem de um sistema de e-commerce de pequeno porte, contemplando a representação estrutural e comportamental do sistema por meio de diagramas.

## Diagramas desenvolvidos

O projeto reúne dois arquivos de imagem:

**1. Modelagem de Dados**
- Diagrama de Modelagem Conceitual;
- Diagrama de Modelagem Lógica.

**2. Diagramas UML**
- Diagrama de Classes;
- Diagrama de Atividades;
- Diagrama de Objetos.

## Objetivo

Aplicar conceitos de análise e modelagem de sistemas, organização de dados e representação de processos, contribuindo para a compreensão da estrutura e do funcionamento de um sistema de comércio eletrônico.

## Linguagens e ferramentas

- Modelagem de dados;
- UML (Linguagem de Modelagem Unificada);
- Ferramentas de criação de diagramas.

## Categoria

Projeto acadêmico — Análise e Desenvolvimento de Sistemas.
